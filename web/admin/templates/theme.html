主题开发说明

themes/<name>/
├── theme.json          # 元信息：name / version / author / description / screenshot
├── templates/
│   ├── home.html       # 首页
│   ├── category.html   # 栏目列表页
│   ├── post.html       # 文章详情页
│   ├── page.html       # 单页
│   ├── tag.html        # 标签页
│   ├── search.html     # 搜索页
│   ├── error.html      # 错误页
│   └── partials/       # 公共片段：head / foot / header / footer / sidebar …
└── assets/
    ├── css/style.css   # 通过 /assets/css/style.css 访问
    └── js/main.js

模板可用变量：{{"{{.Site}}"}}（站点设置）、 {{"{{.Nav}}"}}（主导航）、 {{"{{.SEO}}"}}、 {{"{{.Posts}}"}}、 {{"{{.Post}}"}}、 {{"{{.Pagination}}"}} 等。
可用函数：date、datetime、excerpt、render、safeHTML、default、firstChar、size。
