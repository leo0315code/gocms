# GoCMS — 通用企业站内容管理系统

> 版本：v1.0（首个可交付版本）
> 技术栈：Go 1.22+ / MySQL 8.0 / 标准库 `net/http` + `html/template`
> 定位：通用型企业官网 / 门户站建站系统，一套后台驱动多个站点形态

---

## 1. 项目概述

### 1.1 目标

做一个**开箱即用的通用 CMS**，把「企业官网」这类站点的 90% 共性需求内置掉，剩下的通过主题模板 + 自定义字段扩展。

不追求做成 WordPress 那种插件生态，而是追求：

- **交付即能用**：`go run` 起服务，后台可视化建站，无需前端构建链
- **SEO 友好**：服务端渲染、可选伪静态、自动 sitemap / robots / RSS、结构化数据
- **可二次开发**：清晰的分层、纯 SQL 数据层（无 ORM 黑盒）、模板可替换
- **通用性**：内容模型抽象成「栏目 + 内容 + 自定义字段」，能撑起官网、博客、产品站、新闻门户

### 1.2 目标场景

| 场景 | 说明 |
|---|---|
| 企业官网 | 首页 / 关于我们 / 产品中心 / 新闻动态 / 联系我们 |
| 品牌/产品站 | 产品列表 + 产品详情 + 参数表 + 询价表单 |
| 新闻门户 / 博客 | 多栏目、标签、分页、RSS |
| 机构/政府站 | 多级栏目、公告、单页、附件下载 |

### 1.3 非目标（v1 不做）

- 多站点（多域名绑定）— 预留 `site_id` 设计，v1 单站点
- 可视化拖拽建站器
- 插件市场 / 在线装主题
- 电商下单支付（只做询价表单）
- 多语言 i18n 内容翻译（表结构预留 `lang`）

## 2. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| Web 框架 | 标准库 `net/http`（Go 1.22+ 增强路由） | 零框架依赖，`GET /news/{id}` 原生支持路径参数，长期免维护 |
| 模板 | `html/template`（SSR） | SEO 天然友好、无前端构建、后台与前台共用一个模板引擎 |
| 数据库 | MySQL 8.0 + `github.com/go-sql-driver/mysql` | 用户指定；InnoDB、utf8mb4 |
| 数据访问 | 纯 `database/sql` + 轻量 Repository | 无 ORM，SQL 完全可控可调优，便于 DBA 接手 |
| 会话 | 服务端 Session 表 + HttpOnly Cookie | 无 Redis 依赖，单机即跑；可后续换 Redis |
| 密码 | `golang.org/x/crypto/bcrypt` | 行业标准，成本因子 12 |
| HTML 净化 | `github.com/microcosm-cc/bluemonday` | 富文本防 XSS，白名单过滤 |
| Markdown | `github.com/yuin/goldmark` | 正文支持 Markdown 撰写 |
| 富文本编辑器 | 内置极简 contenteditable 编辑器（无外部 CDN） | 离线可用、无第三方依赖、体积小 |
| CSS | 手写原生 CSS + CSS 变量（暗色/亮色） | 无 Tailwind 构建步骤，改主题只动 CSS 变量 |
| 日志 | `log/slog`（标准库结构化日志） | 结构化、分级 |

**依赖总数：5 个直接依赖**（mysql driver、bcrypt、bluemonday、goldmark、goldmark 的扩展）。全部为纯 Go，交叉编译零障碍。

## 4. 功能清单

### 4.1 内容管理

- **文章（Post）**：标题、Slug、摘要、正文（富文本/Markdown）、封面、分类、标签、状态（草稿/已发布/回收站）、置顶、推荐、浏览量、SEO 三要素、定时发布
- **单页（Page）**：关于我们、联系我们等固定页面；支持自定义模板、排序、导航显示开关
- **分类（Category）**：树形无限级、Slug、排序、SEO、模板指定、栏目图标/封面
- **标签（Tag）**：多对多
- **媒体库**：上传图片/文件、缩略图、按类型筛选、删除校验
- **导航菜单**：多菜单（主导航/页脚/侧栏）、树形结构、自定义链接、排序
- **轮播（Banner）**：图片、标题、副标题、链接、排序、启用
- **友情链接（Link）**：名称、URL、Logo、排序
- **留言/询价（Message）**：姓名、电话、邮箱、内容、来源页、IP、状态（未读/已读/已回复）、后台回复
- **自定义字段（Field）**：给分类挂载额外字段（如产品的「规格」「价格」），值存 JSON — 让 CMS 变通用

### 4.2 系统功能

- 后台登录（bcrypt + 会话 + 登录失败限流）
- 用户与角色（admin / editor / viewer 三级权限）
- 系统设置（站点名、Logo、SEO 默认值、备案号、联系方式、每页条数、开关项）
- 主题管理（列出 `themes/` 下可用主题，切换）
- 数据概览（文章数、留言数、今日 PV）
- 数据库备份导出（mysqldump 可选，v1 提供 SQL 导出）

### 4.3 前台功能

- 首页（轮播 + 推荐栏目 + 最新文章 + 单页区块）
- 栏目列表页（分页）
- 文章详情页（上一篇/下一篇、相关文章、面包屑、浏览量自增）
- 单页
- 搜索（标题/摘要/正文 LIKE，可切全文索引）
- 标签页
- 留言表单（CSRF + 频率限制 + 敏感词可选）
- sitemap.xml / robots.txt / RSS 2.0
- 404 / 500 友好页
- 深浅色主题切换（CSS 变量 + localStorage）

## 5. 数据库设计

> 全部表 InnoDB / utf8mb4_unicode_ci；主键 `BIGINT UNSIGNED AUTO_INCREMENT`；带 `created_at`/`updated_at`；软删除主要用 `status` 字段或 `deleted_at`。

### 5.1 表清单

| 表名 | 说明 | 关键点 |
|---|---|---|
| `users` | 后台用户 | username 唯一、password bcrypt、role、last_login_* |
| `sessions` | 会话 | token 唯一索引、expires_at 索引 |
| `categories` | 分类 | `parent_id` 自关联树、`type` 区分文章/产品栏目 |
| `posts` | 文章 | `category_id`、`status`、`published_at`、`views`、SEO 字段 |
| `pages` | 单页 | `slug` 唯一、`template`、导航开关 |
| `tags` | 标签 | name 唯一、slug |
| `post_tags` | 文章-标签关联 | 联合主键 |
| `media` | 媒体库 | path、mime、size、宽高、上传人 |
| `menus` | 菜单 | `key` 标识菜单位（main/footer） |
| `menu_items` | 菜单项 | `parent_id` 树、link_type（custom/post/page/category）、排序 |
| `banners` | 轮播 | 排序、启用 |
| `links` | 友链 | |
| `messages` | 留言 | status、ip、reply、replied_at |
| `settings` | 设置 | `key` 唯一、`value` TEXT、`group` |
| `fields` | 自定义字段定义 | `category_id`、name、label、type、options、required |
| `post_field_values` | 自定义字段值 | post_id + field_id 联合唯一，`value` TEXT |

### 5.2 核心字段定义

详见 `internal/database/migrations/0001_init.sql`（唯一真实来源，文档与代码保持同步）。

关键索引：

```sql
posts:        idx(status, published_at), idx(category_id), idx(slug) UNIQUE
categories:   idx(parent_id), idx(slug) UNIQUE
menu_items:   idx(menu_id, parent_id, sort)
messages:     idx(status, created_at)
sessions:     idx(token) UNIQUE, idx(expires_at)
settings:     idx(`key`) UNIQUE
```

### 5.3 状态枚举

| 字段 | 值 | 含义 |
|---|---|---|
| `posts.status` | `draft` / `published` / `trash` | 草稿 / 已发布 / 回收站 |
| `messages.status` | `unread` / `read` / `replied` | 未读 / 已读 / 已回复 |
| `users.role` | `admin` / `editor` / `viewer` | 全部权限 / 内容管理 / 只读 |
| `fields.type` | `text` / `textarea` / `number` / `select` / `image` / `date` | 字段类型 |

### 6.3 URL 风格

- 默认「路径风格」：`/a/hello-world`、`/c/news`、`/p/contact`、`/t/标签`
- 兼容「伪静态」：在上面任一 URL 后追加 `.html` 同样可访问（`/a/hello-world.html`）。
  实现方式是在 `ServeMux` 匹配**之前**由 `stripHTMLExt` 中间件剥掉 `/a/ /c/ /p/ /t/` 前缀后的 `.html`，
  否则 `/a/{slug}` 会先把 `hello-world.html` 当成 slug 捕获，导致 404。
  > 部署注意：Nginx 不要再做 `.html` 重写/剥离，必须把原始 URL 透传给 Go。
- 所有前台列表页统一 `?page=N` 分页

## 7. 安全设计

| 风险 | 措施 |
|---|---|
| SQL 注入 | 全部 `database/sql` 参数化占位符；拼接通用的 `IN (?)` 用动态占位符生成，禁止字符串拼用户输入 |
| XSS | 模板默认 `html/template` 自动转义；富文本经 `bluemonday` 白名单净化后以 `template.HTML` 输出；Markdown 走 goldmark + bluemonday（`UGCPolicy`） |
| CSRF | 双提交 Cookie + 隐藏字段双校验，所有 POST 强制校验；token 绑定 session id，用 `crypto/subtle.ConstantTimeCompare` 比对 |
| 密码 | bcrypt cost=12；强度校验（≥8 位） |
| 会话固定 | 登录成功后重新生成 session token；Cookie 设置 `HttpOnly`、`SameSite=Lax`，生产环境 `Secure` |
| 暴力破解 | 登录失败计数（同 IP + 同用户名，5 次锁 15 分钟，内存计数）；**登录成功后重置该计数**，否则正常用户连续登录 5 次会被自己的成功操作锁死 |
| 上传 | 白名单扩展名 + MIME 嗅探 + 大小限制（默认 10MB）+ 随机文件名 + 禁止路径穿越；上传目录不解析脚本 |
| 越权 | 中间件 `RequireRole`；后台所有写操作校验 `admin/editor`，用户管理仅 `admin` |
| 信息泄露 | 生产模式隐藏详细错误页；日志不记录密码/密文 |
| 点击劫持 | 响应头 `X-Frame-Options: SAMEORIGIN` |
| 其他头 | `X-Content-Type-Options: nosniff`、`Referrer-Policy`、CSP（主题资源宽松白名单） |

## 8. 主题系统

### 8.1 主题结构

```
themes/<name>/
├── theme.json            # {name, version, author, description, screenshot}
├── templates/
│   ├── layout.html       # 基础布局（define "layout"）
│   ├── home.html
│   ├── category.html
│   ├── post.html
│   ├── page.html
│   ├── tag.html
│   ├── search.html
│   └── partials/         # header/footer/sidebar/pagination 等
└── assets/
    ├── css/style.css
    └── js/main.js
```

### 8.2 模板约定

- 每个页面模板 `{{define "content"}}...{{end}}`，由 `layout.html` 统一包裹
- 公共变量：`{{.Site}}`（站点设置）、`{{.Nav}}`（主导航树）、`{{.Seo}}`、`{{.User}}`、`{{.Flash}}`、`{{.CSRF}}`、`{{.Year}}`
- 页面数据：`{{.Data}}` 内按页面类型注入（如 `Post`、`Posts`、`Category`、`Pagination`）
- 函数：`safeHTML`、`md`、`date`、`excerpt`、`add`、`sub`、`seq`、`urlquery`、`asset`

### 8.3 切换

设置表 `theme` 键值控制；后台 `/admin/theme` 列出 `themes/*/theme.json` 供切换。切换后模板缓存自动失效。

## 12. 运行方式

开发：

```bash
cd ~/Desktop/code/gocms
cp .env.example .env        # 按需修改数据库账号密码
go run ./cmd/gocms          # 自动建库 + 建表 + 初始化管理员 + 演示数据
# 前台 http://localhost:8090
# 后台 http://localhost:8090/admin   账号见 .env 的 ADMIN_USER / ADMIN_PASS
```

> `ADMIN_PASS` 只在**首次创建管理员**时生效；账号已存在后改 `.env` 不会改密码，
> 请到「后台 → 个人资料」修改。

用 Makefile：

```bash
make run        # 开发运行（模板热重载）
make build      # 编译当前平台
make start      # 后台启动（日志在 .run/gocms.log）
make stop
make check      # gofmt + go vet
```

生产：

```bash
make build-linux                                   # 交叉编译
# 或：GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o gocms ./cmd/gocms
```

完整的服务器部署（systemd + Nginx + 备份 + 升级 + 排错）见 [`03-部署指南.md`](./03-部署指南.md)。
