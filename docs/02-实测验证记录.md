## 三、本轮修复的缺陷

实测过程中发现并修复了 11 个真实缺陷：

| # | 缺陷 | 影响 | 修复 |
| --- | --- | --- | --- |
| 1 | `hero.html` 里写的是 `{{define "content"}}` + `{{template "layout"}}`，与首页引用的 `{{template "hero"}}` 不匹配 | 首页 500：`no such template "hero"` | 改为 `{{define "hero"}}` |
| 2 | 模板逻辑名无 `.html` 后缀，`html/template` 找不到 | 全部页面 500 | Render/RenderAdmin 增加 `name+".html"` 回退 |
| 3 | flash cookie 直接塞中文 | `net/http: invalid byte in Cookie.Value`，提示丢失 | 写入 `url.QueryEscape`，读取 `url.QueryUnescape` |
| 4 | `parseForm` 对所有请求调 `ParseMultipartForm` | 普通 urlencoded 表单报「表单过大或解析失败」，后台所有保存失效 | 按 `Content-Type` 分流 `ParseForm` / `ParseMultipartForm` |
| 5 | `.html` 伪静态失效 | `/a/foo.html` 404 | 加 `stripHTMLExt` 中间件在 ServeMux 前改写路径 |
| 6 | 种子数据先建菜单项、后建单页 | 导航与页脚的「联系我们」`href=""` | 调整顺序为先建单页，菜单回填真实 page ID |
| 7 | 设置页把全部分组一起渲染，保存时覆盖全部分组 | 左导航点击无反应；保存单组会把其他组的 bool 误写为 0 | 按 `?group=` 过滤渲染，保存时只处理当前分组 |
| 8 | 限流器成功登录也扣配额；`map` 无锁 | 连续登录 5 次自锁；并发下有 fatal error 风险 | 成功登录 `Reset(key)`；`Limiter` 加 `sync.Mutex` |
| 9 | 设置页图片字段（站点 Logo / 图标）的「选择」按钮比输入框矮 3.25px | 顶部对齐但高度不一致，视觉粗糙 | `.img-field` 改 `align-items: center`，按钮固定 `height: 34px`（与输入框实测等高），`input` 加 `flex: 1` |
| 10 | 列表页操作列的「预览 / 编辑」被压成竖排两行（文章、单页、栏目三个列表均复现） | 行高被撑大、操作区难看 | `.col-actions` 的 `width: 1%` 叠加 `.btn-group` 的 `flex-wrap: wrap`，列宽被压到单个按钮宽度；补 `table.data .col-actions .btn-group { flex-wrap: nowrap; }` |
| 11 | 栏目管理页顶部「共 0 个栏目」，实际列表有 5 条 | 统计数字始终为 0，误导用户 | `CategoryList` 从未给 `d.Total` 赋值，补 `d.Total = len(flat)` |

另外修复的样式问题：

- 首屏轮播无背景图时过于空洞 → 加渐变光晕 + 点阵兜底背景（`.hero::before` / `::after`）
- `.hero-content` 同时套 `container` 和额外 `padding-left` 导致文字居中偏移 → 改为整栏容器 + 文字限宽 720px
- 媒体库拖拽区 `<label>` 默认 `inline`，块级子元素撑坏盒模型 → `display: block`，file input 选择器改为 `input[type="file"]`
- 媒体库操作按钮文字被挤成两行 → 加 `white-space: nowrap`，网格最小宽度 148 → 168px
- 模板里误用 `.SiteName` 拼出「云启科技 10MB」 → 改为真正传 `MaxMB`

清理的垃圾文件：`internal/handler/XXc9G1BO`（与 `admin_content.go` 完全相同的误生成副本）、
`XXy1BvZn`（.env 副本）、4 个编辑器临时副本（`*.go.<digits>`）。

## 五、已知限制（非缺陷，属 v1 范围外）

| 项 | 说明 |
| --- | --- |
| 删除为物理删除 | 无回收站；删除栏目时会先把子栏目上提、文章 `category_id` 归零，不会级联删文章 |
| 单站点 | 表结构未加 `site_id`，多站点需改表 |
| `content_format` 双模式 | html / markdown 二选一，同一篇内不混排 |
| 搜索用 `FULLTEXT` | 中文分词依赖 MySQL `ngram` 解析器；若未启用，中文搜索按整词匹配，建议生产环境开启 `ngram_token_size=2` |
| 限流为单机内存 | 多实例部署需换 Redis |
| 验证码 | 留言用蜜罐字段（`website`）防机器人，无图形验证码 |
